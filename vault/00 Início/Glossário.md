# Glossário

Os termos próprios do Mk, em ordem alfabética, com a nota que os explica.

## Termos

| Termo | O que é | Nota |
|---|---|---|
| **Ajustes** | A folha de configurações (`Super + ,`), no meio da tela | [[Ajustes]] |
| **ajustes.json / ajustes.lua** | O que o usuário escolheu nos Ajustes; o `.lua` é a parte do Hyprland | [[Ajustes]], [[Pasta do usuário]] |
| **aur-pendentes.txt** | Pacotes do AUR que ficaram fora da instalação e o `mk-update` oferece | [[AUR na instalação]] |
| **canal** | O repositório git público de onde um Mk instalado se atualiza | [[Canal de lançamentos]] |
| **direção Folha** | A linguagem visual: preto quente, osso, cobre, folha de desenho técnico | [[Direção Folha]] |
| **ganchos do limine** | `limine-mkinitcpio-hook` e `limine-snapper-sync` (AUR) | [[Ganchos do limine]] |
| **ilha** | A barra do Maré, pendurada no meio da borda de cima | [[Ilha]] |
| **Maré** | O shell do Mk, em Quickshell/QML | [[Maré]] |
| **marca `.instalado-pelo-mk`** | Arquivo que diz que uma pasta é do Mk e pode ser trocada | [[Marca instalado-pelo-mk]] |
| **migração** | Script que roda uma vez para levar a um Mk instalado o que mudou fora de `<raiz>` | [[Migrações]] |
| **mk-aur** | O repositório pacman local, dentro da ISO, com o AUR já compilado | [[AUR na instalação]] |
| **`mk`** | O comando do terminal do Mk | [[Comando mk]] |
| **painel** | O que desce da ilha quando se clica num item | [[Painéis]], [[Painel líquido (Tide)]] |
| **passageiro** | `toast` e `osd`: aparecem e voltam sozinhos | [[Notificações e OSD]] |
| **perfil de hardware** | `amd`, `intel`, `nvidia`, `vm`: seções de drivers | [[Microcódigo e perfis de hardware]] |
| **projeto** | Um repositório git em `~/Work` ligado a um workspace | [[Projetos e workspaces]] |
| **`<raiz>`** | A pasta acima do shell, normalmente `~/.config/mk` | [[Pasta do usuário]] |
| **skel** | `/etc/skel`: de onde a home de um usuário novo é copiada | [[Usuários e sudo]] |
| **Tide** | O painel "líquido" que escorre da ilha | [[Painel líquido (Tide)]] |
| **VERSION / NOVIDADES** | A versão instalada (`commit data`) e o que chega com um lançamento | [[Canal de lançamentos]] |
